# C++ / WASM 実装方針

このディレクトリは日本アニメ総合検索サイトの計算主体を実装する。

- `shared/` : CSV解析、共通データ保持、共通6ソート、検索共通処理
- `all/` : `all.wasm` 用エントリポイント
- `search/` : `search.wasm` 用エントリポイント
- `tests/` : ネイティブC++テストとWASM ABIスモークテスト

## 速度設計

- CSVはロード時に一度だけ解析する。
- レコード本体を検索結果ごとに複製せず、結果はレコードindex配列で保持する。
- CSVフィールドは連続した文字プールへ保持し、各セルはoffset/length参照とする。
- `search.wasm` と `all.wasm` は同じ共有ソースを使うが、成果物は別バイナリにする。
- JSへは1件ずつ返さず、一定件数のJSONチャンクとしてまとめて返す。
- `-O3 -flto` でビルドし、例外・RTTI・ファイルシステムを無効化する。

## データ安全性

CSV追加は一度テンポラリ領域で解析・検証し、成功した場合だけ正式Datasetへマージする。ヘッダー不一致、UTF-8不正、RFC 4180構文異常、内部ID重複があったCSVは既存正常データへ反映しない。

## 現時点の検索API

検索エンジンはUIの解釈を持たず、次の低レベル条件を受ける。

- 文字列: 完全一致 / 前方一致 / 部分一致
- 複数条件: AND / OR
- 条件単位の除外: NOT相当
- 数値範囲
- 日付範囲
- 共通6ソート

UI側はこれらを検索ロジックとして実装せず、WASMへ条件を渡す橋渡しだけを行う。
