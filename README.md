# 日本アニメ総合検索サイト

GitHub・CSV・WASM統合型の日本アニメ総合検索サイト。

このリポジトリでは、実装設計資料で確定した責務分離を基準に実装する。

## 確定ページ構成

- `/` — トップページ
- `/search/` — 検索ページ
- `/all/` — 全件表示ページ
- `/detail/?id=A00000001` — 詳細ページ

## 基本責務

- GitHub: 保存 / 履歴 / Actions / Pages
- CSV: 作品データの正本
- `search.wasm`: 検索・条件判定・検索結果ソート
- `all.wasm`: 全件読込・全件出力・全件ソート
- JavaScript: UI / HTTP取得 / WASMとの受け渡し / DOM描画
- Gemini API: 取得済み事実を基にした概要生成

## JavaScriptで行わない処理

JavaScript側では次を行わない。

- CSV内容の解析・正規化
- 年代・四季・ジャンル・媒体・スタッフ等による事前絞り込み
- 検索結果・全件一覧の並び替え計算
- 検索一致度の計算
- AND / OR / NOT の意味解釈
- 日付範囲・数値範囲の判定

JavaScriptはUI入力を受け取り、WASMへ渡し、WASMから返った結果をDOMへ描画する橋渡しに限定する。

## 共通ソート

検索ページと全件表示ページは次の6種類を共通で使用する。

1. 四季順
2. 年代順
3. タイトル順
4. 制作会社名順
5. 話数順
6. 総時間順

昇順 / 降順を切り替えられる。

## 現在の実装範囲

現在は情報取得元・作品データへ接続する前段として、情報以外のUIと接続境界を整備している。

実装済み:

- ポップで明るい共通デザイン
- PC / モバイルのレスポンシブナビゲーション
- トップ / 検索 / 全件表示 / 詳細の4画面
- 検索条件UI
- 共通6ソートUI
- 全件表示の段階描画用状態UI
- 詳細ページの内部ID受け取り経路
- `search.wasm` / `all.wasm` 接続前提のJavaScript境界
- エラー / 状態表示の共通UI
- キーボードフォーカス、reduced-motion等の基本アクセシビリティ

未接続:

- 作品CSV
- `search.wasm`
- `all.wasm`
- 外部情報取得
- Gemini概要生成
- 自動更新Actions

## 既存ファイルの保護

既存のハッシュ生成ページは `legacy/hash-generator.html` に退避して保持している。

既存の `top.html` は現在の4ページ構成から参照していないが、既存機能保護のため削除していない。

## データ実装時の原則

- 初期導入CSVと四半期CSVは同一スキーマにする。
- 作品情報を検索高速化のため別形式へ複製しない。
- `master.csv` や作品情報複製インデックスを作らない。
- `manifest.csv` を使用する場合はCSVファイル名のみを保持する。
- 詳細ページは新規検索エンジンを作らず、`search.wasm` の内部ID完全一致取得を使用する。
- `search.wasm` と `all.wasm` は別バイナリにして障害範囲を分離する。
